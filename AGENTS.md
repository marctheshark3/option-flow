# Contributing to Option Flow

Keep the skill portable and focused on experiment and delivery constraints.
Preserve the distinction between a diagnostic lens and a calibrated model.
Maintain evidence, user scope, acceptance criteria, and comparable measurement.

Keep substantial conditional guidance in the linked reference. Add runtime
scripts only when a repeated deterministic operation warrants them. Evaluation
fixtures are synthetic development resources, outside the installable skill.

Run `python3 dev/check.py` after changes. For substantial behavior changes, use
an independent agent with the skill, a realistic task, and raw artifacts, keeping
the evaluator's expected outcome out of its context. Use isolated workspaces and
record the actual result and its limitations. Fixture tests alone do not prove
that the instructions improve agent behavior.

Publish changes through a pull request with independent review. The initial
source release receives the same review before repository publication. Keep
deployment policy, private environments, account records, and agent transcripts
outside this public package.
